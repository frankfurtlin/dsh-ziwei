# 紫微斗数插件 · 设计评审

日期：2026-11-19
范围：DSH 面板内的排盘 / 合盘 / 古籍 / 百科四视图，表单页、生辰管理、分享弹层；桌面 1440×900 与手机 390×844。
截图：`verification/design-review/`。

## 一句话结论

气质方向是对的（纸感米白 + 墨金 + 宋体标题，有古籍感，也压得住盘面），
但 **层级没有收敛、字阶太碎、语义色太多、主操作不突出**。
盘面的「信息密度 + 对比度」和工具条的「四层堆叠」是最影响完成度的两个点；
改这两处，观感会从“能用”跳到“精致”。

## 现在做得好的地方

- 米白纸感 + 墨金强调，和紫微斗数“命书 / 古籍”的气质匹配，比常见的深色科技风更适合这个内容。
- 概览条把「命宫 · 巨门 | 土五局 | 格局 3 个」前置，盘面未展开就能读到结论，信息架构是对的。
- 盘面 12 宫结构完整，四化、大限、流年都没有被砍掉；手机端也已做到不横向溢出。
- 生辰管理弹层克制：行内操作 + 二次确认，没有过度设计。
- 右侧「命理解读」与盘面并置，边看盘边问，比“先起盘再跳聊天”顺。

## 问题与建议

### P0-1 工具条四层堆叠，主视觉被挤到 28% 以下

现状（1440×900）：外壳 tab 栏（`紫微斗数 排盘 合盘 古籍 百科`）→ 插件工具条
（`重新起盘 / 分享命盘 / 最近生辰 / 生辰管理 / 复制盘面摘要 / 已恢复…忘记`）→
概览条（`命宫 · 巨门 …` + `展开命盘概览`）→ 本命/大限/流年分段控件，四层都做成
“白底 + 1px 边 + 圆角”的同一种卡片，视觉权重几乎相等。盘面从 y≈250 才开始。

建议：

- 盘面操作收成一条：`← 重新起盘`（主）+ `分享` + `⋯`（最近生辰 / 生辰管理 / 复制摘要 / 忘记）。低频的「刷新」「新窗口打开」交给外壳或 `⋯`。
- 「已恢复上次记住的生辰（2026-11-19 保存）·忘记」降级成概览条右侧的一行 meta，不再单独占一行。
- 「最近生辰 ▾」与「生辰管理」合并为一个「生辰 ▾」菜单：前 5 条 + 「管理全部…」，减少一个常驻按钮。
- 目标：盘面顶部到 y≈170，四层变两层。

### P0-2 盘面没有字阶，信息同权重

12 个宫里同时存在：宫名（10px 灰）、干支（10px 灰）、大限岁数（10px 灰）、
主星（15–16px 金/紫）、辅星列（10px 多色）、杂曜（9px 灰）、四化小标（9px 红/绿/蓝/黄）、
命宫印章。字号只有 9/10/15 三档，且 9 与 10 肉眼不可分。

建议建立三级（以 1440 面板为基准，手机端按 0.9 缩放）：

| 层级 | 内容 | 字号 / 字重 / 颜色 |
| --- | --- | --- |
| L1 | 主星 | 18px / 600 / 墨色或专属主星色 |
| L2 | 辅星（左辅右弼、文昌文曲、天魁天钺…） | 12px / 500 / #6f6a60 |
| L3 | 杂曜、干支、大限岁数 | 10.5px / 400 / #9a948a（reduced 60%） |

宫名固定在左上，干支右上，岁数只在「大限」层显示（切回本命时隐藏），
减少每格 3 行常驻小字。

### P0-3 语义色太多，且没有图例

现在同时承载意义的颜色：金色（主星/链接/描边）、淡紫（当前大限宫位）、
红 / 绿 / 蓝 / 黄（四化）、蓝（性别选中）、红（删除）。用户看不出
“星名金色”和“化禄绿色”是不是一个体系；当前大限的淡紫又是全站唯一冷紫。

建议收敛为两套语义：

1. **四化只保留 4 色**：禄=绿、权=蓝、科=黄、忌=红，仅用于四化徽标与对应星名的小圆点，不做大色块。
2. **层级 / 选中只用墨与金**：当前大限的宫位改「1px 金边 + 5% 金底」，去掉紫色；命宫用左侧 2px 金线常驻。
3. 底部「化禄 / 化权 / 化科 / 化忌」四个 chip 前加“生年四化”标签，或做成 hover 才展开的说明，不再和「点击宫位看三方四正」混排。

### P0-4 交互文字对比度不足

米白底 `#faf7f0` 上的金色 `#b08d57` 约 2.6:1，`展开命盘概览`、`忘记`、
`最近生辰 ▾` 这类可点文字都低于 4.5:1；9–10px 的灰字 `#8a8378` 同样偏低。

建议：交互文字统一用深棕 `#6b4f2a`（≈5.2:1），金色只做装饰线与大按钮；
正文字灰提到 `#6f6a60`，且正文不小于 12px。改完跑一次对比度检查
（`scripts/` 里可以加个 axe 断言的轻脚本）。

### P0-5 解读面板空态浪费了 420×600 的空间

右侧空态只有一句「已恢复上次生辰的命盘…」+ 6 个 tab，占了五分之一屏却什么都不给。

建议空态改成三块：

1. 一句结论摘要（复用概览条的命宫/五行局/格局），2 行内；
2. 主 CTA「生成命格总览」（自动跑一次解读，等于替代 `autoRun` 的隐式行为）；
3. 2–3 个示例问题 chip（`今年适合换工作吗？`、`感情上要注意什么？`），点击即填充并发送。

追问输入框在空态时禁用或半透明，避免“输入了但不会出结果”的困惑。

### P1-1 字体没有矩阵

标题/盘面是宋体，正文/表单/按钮是系统无衬线，`ZI WEI DOU SHU` 全大写
+ 3px 字距，姓名 `frank` 又用无衬线粗体插进标题行，三种气质叠在一起。

建议明确两族 + 一类数字：

- 标题 / 盘面主星 / 弹层标题：宋体（Noto Serif SC 或本地思源宋）；
- UI 正文 / 表单 / 按钮：无衬线（系统栈）；
- 干支、日期、岁数、时间戳：`font-variant-numeric: tabular-nums`，避免跳动。

姓名不要进盘面标题：放在概览条（`frank · 2000-10-25 子时 · 男`）或分享卡里。

### P1-2 表单细节

- 卡片顶部三段装饰线不等长（455–575 / 580–830 / 835–1032），像被截断的进度条；
  改为等分三段，或一条整线 + 中央菱形。
- 原生 `<select>` 的箭头贴边、大小不一，和自定义边框不搭；建议自绘 chevron，统一右内边距。
- 性别选中态是系统蓝 `#2563eb`，全站唯一冷色；建议改「墨底 + 金描边」或「浅金底 + 深棕字」。
- 「立即起盘」金色渐变 + 阴影是全页最重元素，层级上真正的主操作却是「重新起盘」；
  建议按钮只保留三档：主（实心墨/金）、次（描边）、危险（红描边），去掉渐变。

### P1-3 生辰管理

- 每行缺少视觉锚点：姓名应成为行标题（加粗），性别用符号，日期/时辰做副行；时间戳精确到秒没有意义，改「3 天前保存」。
- 「当前」badge 可以做成金色小圆点 + 文字，比灰胶囊更有“当前”的质感。
- 删除、清空同为红描边，建议清空降为文字按钮，避免和单条删除抢注意力。

### P1-4 移动端

- 390px 下宫格约 90px/格，杂曜仍是 9–10px；实测不溢出但可读性临界。
  建议手机端默认「只显示主星 + 四化」，辅星/杂曜折叠为 `+5` 点开，或提供盘面/列表切换。
- 工具条按钮 32px 高、12px 字，低于 44px 触控标准；建议只留 2 个主操作 + 「更多」。
- 手机空态占比更大，注意别把盘面推到首屏外（当前 844 高度下 OK，再往上要注意）。

### P2 系统性

- **tokens 化**：目前大量内联 `style={{...}}`（`toolbarButtonStyle`、卡片、tint 色）；
  建 `--ziwei-*` 变量（色、字阶、间距 4/8/12/16/24、圆角 8/12/16、描边 1px hairline），
  替换后暗色主题、窄面板都好维护。
- **暗色**：DSH 外壳支持 `data-theme`，插件目前固定米白；确认暗色外壳下不刺眼（verify 有配色断言，但只测了部分）。
- **可访问性**：弹层 `Esc` 关闭、焦点陷阱、图标按钮 `aria-label`、宫位 `tabindex` + 键盘选择。
- **IA 一致性**：合盘页有 `‹ 排盘 | 合盘分析` 页头，排盘页没有；同层级视图建议统一走外壳 tabs。
- **「让 DSH 解读」与右栏解读关系**：两个入口功能重叠，加一句区分（“在聊天里继续”“在面板内快速解读”）或合并。

## 如果实施：建议顺序

| 阶段 | 内容 | 预估 |
| --- | --- | --- |
| Phase 1（观感提升最大） | P0-1 工具条收敛、P0-2 盘面三级字阶、P0-3 色彩语义收敛、P0-4 对比度 | 0.5–1 天 |
| Phase 2（细节质感） | 字体矩阵、表单细节、按钮体系、生辰管理行、空态 CTA | 0.5 天 |
| Phase 3（系统化） | tokens、暗色、可访问性、移动端盘面简化 | 1 天 |

每个 Phase 结束跑 `scripts/check.sh` 并出 390 / 768 / 1440 三档截图，改动集中在
`app/app/globals.css`、`app/components/*` 与 `client.js`，不碰盘面计算逻辑。

## 实施记录（2026-11-19）

按上面的优先级落地，功能与数据格式不变，只动样式、排版与交互：

- **P0-1 工具条**：收成「重新起盘（主）/ 分享命盘 / 生辰 N ▾ / ⋯」，恢复与分享提示并进概览条；
  生辰下拉里放最近 5 条、「管理全部生辰…」「清空全部记录…」，`⋯` 里放复制摘要与忘记。
  两个下拉都支持点外关闭与 Esc。
- **P0-2 盘面字阶**：主星 17/600 是唯一大字号；辅星 11、宫名/干支/岁数 10.5–11、单色灰；
  大限浅金底 + 金描边、选中墨色描边、三方四正 1px 墨线；中央大限改成金框卡片；图例改圆点。
- **P0-3 语义色**：四化收敛成 `--zw-lu/quan/ke/ji` 四个 token，金/墨只做结构色；
  正文弱化色 `--t-faint` 从 0.52 提到 0.62。
- **P0-5 解读空态**：改成「{名字}的这张盘，先看命格」+「生成命格总览」+ 3 个示例问题。
- **P1 字体矩阵**：标题衬线、正文无衬线、数字 tabular；表单去掉三段装饰线，改
  `BIRTH DATA / 出生信息` 发丝线标题；select 换 SVG chevron；性别选中墨底；提交墨底；
  统一 `.zw-btn / .zw-btn-primary / .zw-btn-ghost / .zw-text-btn`。
- **P1 管理行**：姓名为主、生辰为副，保存时间改相对格式（title 仍是精确时间）。
- **P1/P2 移动端与可达性**：≤560px 辅星折叠成 `+N`、主星 14.5px、宫格 66px；
  ≤900px 按钮 40px；管理/分享弹层支持 Esc 与 Tab 焦点循环；宫格可 Tab + Enter/Space；
  暗色补齐 `--t-*`；合盘页嵌入面板时不再叠自己的顶栏；client.js 的刷新 / 新窗口收进 `⋯`。
